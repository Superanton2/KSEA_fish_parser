# Опис датасету zakaz_fish

Файл згенеровано з `zakaz_fish/dictionary.py`, не редагуйте вручну.

## Загальні примітки

- Датасет: товари категорії «Риба та морепродукти» з zakaz.ua (агрегатор супермаркетів), місто задається в конфігу (за замовчуванням Київ).
- Один рядок у products це один товар. Дату збору дивіться в scraped_at / last_seen / details_scraped_at (UTC, ISO 8601).
- Ціни зберігаються в копійках (цілі числа): 19900 = 199.00 грн. Одиниця ціни залежить від unit_kind: per_kg це ціна за 1 кг, pack це ціна за упаковку (розмір у pack_qty + pack_unit).
- price_min_kop і price_max_kop це мінімальна і максимальна ціна серед магазинів, які бачить сайт; якщо магазин один або ціни однакові, значення рівні. Розбивки по магазинах у цьому датасеті немає.
- У listing_prices один товар може повторюватись по одному разу на кожну категорію, де він знайдений. Щоб отримати один рядок на товар, відфільтруйте category_slug = 'fish-and-seafood-zakaz' (батьківська категорія).
- Батьківська категорія містить і нерибні товари (горілка, кава та ін.) та рибу з дерева «Заморозка». Для відбору використовуйте cat_l1 / cat_l2 / cat_l3 з products.
- Порожнє значення означає «на сайті цього немає», а не нуль. Це стосується бренду, виду, виробника, складу і КБЖУ.
- Опис товарів (description) не зберігається за налаштуванням store_descriptions = false.
- Фото не завантажувались, лише посилання (image_url).

## Аркуш `products`

| Поле | Опис |
|---|---|
| `product_id` | Ідентифікатор товару на zakaz.ua, ключ. Хвіст URL після останнього «--». 14 цифр з провідним 0 (штрихкод) або <id мережі> + 14 цифр (товар однієї мережі). |
| `id_type` | Тип ідентифікатора: ean (штрихкод), chain (власний/ваговий товар мережі), other (не розпізнано). |
| `ean13` | Штрихкод EAN-13 (product_id без провідного 0). Лише для id_type = ean. |
| `ean13_valid` | 1 якщо контрольна цифра EAN-13 сходиться, 0 якщо ні. Невалідні (близько 6%, переважно коди 800…) це, імовірно, внутрішні коди постачальника, а не справжні штрихкоди: для зіставлення з іншими базами не використовувати. |
| `chain_id` | Мережа, якій належить товар (novus, auchan, metro…). Лише для id_type = chain. |
| `url` | Посилання на сторінку товару на zakaz.ua. |
| `slug` | Текстова частина URL (до «--»). Генерується з назви, може змінюватись, ключем не є. |
| `title` | Назва товару, як на сайті. |
| `weight_text` | Вага/одиниця як показано на картці: «за 1 кг», «250 г». Може бути порожнім (наприклад, устриці поштучно). |
| `unit_kind` | Тип одиниці ціни: per_kg (ціна за кг), pack (ціна за упаковку), unknown (не розпізнано). |
| `pack_qty` | Розмір упаковки числом (250 для «250 г»; 1 для «за 1 кг»). |
| `pack_unit` | Одиниця розміру упаковки: г, кг, мл, л, шт. |
| `image_url` | Посилання на фото товару (файли не завантажувались). |
| `brand` | Торгова марка (характеристика «Торгова марка»). «Без ТМ» означає, що марки немає. |
| `producer` | Виробник (характеристика «Виробник»); часто порожній. |
| `country` | Країна-виробник. |
| `species` | Вид риби/морепродукту (характеристика «Вид», напр. лосось, креветка). Порожній приблизно в третині товарів: вид доведеться виділяти з назви. |
| `shelf_life` | Термін придатності текстом, як на сайті («5 діб», «12 місяців»). |
| `storage_temp` | Температура зберігання в °C текстом, як на сайті: «2...6» це від 2 до 6; «-18...-18» це -18. |
| `composition` | Склад, текст з етикетки. |
| `kcal_100g` | Калорійність на 100 г, ккал. |
| `protein_100g` | Білки на 100 г, г. |
| `fat_100g` | Жири на 100 г, г. |
| `carbs_100g` | Вуглеводи на 100 г, г. Часто порожнє: сайт показує, коли вказано. |
| `description` | Маркетинговий опис. Порожній (не зберігається за налаштуванням). |
| `cat_l1` | Категорія рівня 1 з хлібних крихт сторінки товару (slug). Основна: fish-and-seafood-zakaz; також frozen-zakaz та інші. |
| `cat_l2` | Категорія рівня 2 (slug), напр. prepared-fish-zakaz, seafood-zakaz. Назви дивіться на аркуші categories. |
| `cat_l3` | Категорія рівня 3 (slug); може бути порожньою, якщо в дереві є лише два рівні. |
| `first_seen` | Коли товар вперше побачили в списках (UTC). |
| `last_seen` | Коли товар востаннє бачили в списках (UTC). |
| `is_active` | 1 = товар був у списках під час останнього повного збору; 0 = зник. |
| `details_scraped_at` | Коли завантажили сторінку товару з характеристиками (UTC). Порожнє, якщо ще не завантажували. |
| `details_status` | Результат завантаження сторінки товару: ok, empty (сторінка без даних), not_found (404), error. |

## Аркуш `listing_prices_latest`

| Поле | Опис |
|---|---|
| `run_id` | Ідентифікатор запуску збору (дата-час UTC), з якого цей знімок цін. |
| `product_id` | Товар, зв'язок із products.product_id. |
| `city` | Місто, для якого збирали (kyiv). |
| `category_slug` | Категорія, у списку якої знайшли товар. fish-and-seafood-zakaz це батьківська (усі товари); інші це підкатегорії. |
| `scraped_at` | Коли зняли ціну (UTC). |
| `price_min_kop` | Мінімальна ціна серед магазинів, копійки. 19900 = 199.00 грн. Одиниця (кг або упаковка) визначається products.unit_kind. |
| `price_max_kop` | Максимальна ціна серед магазинів, копійки. Дорівнює мінімальній, якщо діапазону немає. |
| `is_promo` | 1 = на картці є позначка акції, 0 = немає. |
| `page` | Номер сторінки списку (по 40 товарів). |
| `position` | Позиція картки на сторінці (1–40). |

## Аркуш `categories`

| Поле | Опис |
|---|---|
| `slug` | Ідентифікатор категорії в URL (zakaz.ua/uk/kyiv/<slug>/), ключ. |
| `name` | Назва категорії українською, як на сайті. |
| `level` | Рівень у дереві: 1 верхній, 2 підкатегорія, 3 підпідкатегорія. |
| `parent_slug` | slug батьківської категорії. |

## Аркуш `chains`

| Поле | Опис |
|---|---|
| `chain_id` | Ідентифікатор мережі на zakaz.ua (novus, auchan, metro…), ключ. Збігається з префіксом product_id товарів мережі. |
| `name` | Назва мережі. |
| `hostname` | Піддомен мережі на zakaz.ua. |
| `logo_url` | Посилання на логотип. |

## Аркуш `stores`

| Поле | Опис |
|---|---|
| `store_id` | Ідентифікатор магазину на zakaz.ua, ключ. |
| `chain_id` | Мережа магазину, зв'язок із chains.chain_id. |
| `zone_hint` | Назва зони доставки зі слота (напр. Mostytsky), підказка до розташування. |
| `city` | Місто магазину. Порожнє: заповнюється вручну (частина магазинів із довідника не в Києві). У цьому датасеті цін по магазинах немає. |
| `source` | Звідки взято запис (delivery_schedules_fixture). |
